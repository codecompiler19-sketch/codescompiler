# PHP - Variable Functions




PHP Variable Handling Functionsare the inbuilt PHP library functions that enable us to manipulate and test php variables in various ways.


# Installation


There is no installation needed to use PHP variable functions; they are part of the PHP core and comes along with standard PHP installation.


## Runtime Configuration


This extension has no configuration directives defined in php.ini.
