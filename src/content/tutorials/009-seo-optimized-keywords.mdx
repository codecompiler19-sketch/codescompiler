# SEO Keyword Optimization

Keywords are the words and phrases people use when looking for information, services, or products. Keyword optimization means understanding those searches and making sure a page answers the relevant need. It does not mean repeating a phrase as many times as possible.

Imagine you teach Python. A broad phrase such as “Python” could mean many things, while “how to sort a list in Python” points to a specific task. A page that demonstrates list sorting and explains the output is a better match for the more specific question.

## Start with search intent

Before selecting a phrase, ask what the searcher likely wants:

- **Learn:** a definition or explanation.
- **Do:** steps to complete a task.
- **Compare:** differences, pros, and cons.
- **Find or buy:** a product, service, or destination.

Review the actual results for a query to understand the type of content people expect. Do not assume that the phrase with the highest estimated search volume is automatically the best target.

## Choose a primary topic and related terms

Each page should have a clear central purpose. List the main question, related subquestions, synonyms, and terminology a reader needs to understand the topic. Use those terms where they fit naturally in the title, headings, examples, and body text.

For a page about sorting Python lists, relevant subtopics could include ascending order, descending order, `sort()`, and `sorted()`. They belong because they help explain the task, not because every phrase must appear a fixed number of times.

## Map topics to pages

Keyword mapping assigns each major topic to the page best suited to answer it. Avoid publishing several near-identical pages that all target the same question. For example, a general “Python lists” lesson and a focused “sort a list in Python” lesson can serve different needs if their content and purpose are clearly distinct.

## Where keywords belong

Use language that accurately describes the page in the title element, main heading, section headings, URL where appropriate, and link text when linking to that page. Add image alt text to describe informative images, not to insert extra keywords.

Google does not use the meta keywords tag for web ranking. There is also no universal keyword-density percentage or ideal word count that guarantees rankings. A meta description may help describe a page in search results, but a search engine can generate its own snippet.

## Avoid keyword stuffing

Unnatural repetition makes content harder to read and can violate search engine spam policies. Write the sentence you would use to explain the idea to a person. If a keyword does not fit, use a natural alternative or omit it.

## Measure and refine

Use search performance data to see which queries bring impressions and clicks. If a page appears for relevant queries but receives few clicks, review the title and snippet. If people arrive but cannot complete the task, improve the explanation, example, or page experience.
