## HTML - QR Code

A QR is an abbreviation, stands for Quick Response code which is a form of 2-D matrix barcode. If we take a closer
    look at a QR Code closely, we will clearly see that it consists of black squares on a white background. It can store
    various types of data including phone numbers, URLs of a website and any type of text up to 4000 characters.
