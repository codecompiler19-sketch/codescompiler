# Python - For Else Loop


Python supports an optionalelse blockto be associated with afor loop. If aelse blockis used with afor loop, it is executed only when the for loop terminates normally.


The for loop terminates normally when it completes all its iterations without encountering abreak statement, which allows us to exit the loop when a certain condition is met.

### Syntax of For Else Loop


Following is the syntax of for loop with optional else block −


```python
for variable_name in iterable:
 #stmts in the loop
 .
 .
 .
else:
 #stmts in else clause
 .
 .
```


### Example of For Else Loop


The following example illustrates the combination of an else statement with a for statement inPython. Till the count is less than 5, the iteration count is printed. As it becomes 5, the print statement in else block is executed, before the control is passed to the next statement in the main program.


```python
for count in range(6):
   print ("Iteration no. {}".format(count))
else:
   print ("for loop over. Now in else block")
print ("End of for loop")
```


On executing, this code will produce the followingoutput−


```python
Iteration no. 1
Iteration no. 2
Iteration no. 3
Iteration no. 4
Iteration no. 5
for loop over. Now in else block
End of for loop
```


## For-Else Construct without break statement


As mentioned earlier in this tutorial, the else block executes only when the loop terminates normally i.e. without using break statement.


### Example


In the following program, we use the for-else loop without break statement.


```python
for i in ['T','P']:
   print(i)
else:
   # Loop else statement
   # there is no break statement in for loop, hence else part gets executed directly
   print("ForLoop-else statement successfully executed")
```


On executing, the above program will generate the following output


```python
T
P
ForLoop-else statement successfully executed
```


## For-Else Construct with break statement


In case of forceful termination (by using break statement) of the loop, else statement is overlooked by the interpreter and hence its execution is skipped.


### Example


The following program shows how else conditions work in case of a break statement.


```python
for i in ['T','P']:
   print(i)
   break
else:
   # Loop else statement
   # terminated after 1st iteration due to break statement in for loop
   print("Loop-else statement successfully executed")
```


On executing, the above program will generate the following output


```python
T
```


## For-Else with break statement and if conditions


If we usefor-elseconstruct withbreak statementandif condition, thefor loopwill iterate over the iterators and within this loop, you can use anif blockto check for a specific condition. If the loop completes without encountering abreak statement, the code in the else block is executed.


### Example


The following program shows how else conditions works in case of break statement andconditional statements.


```python
# creating a function to check whether the list item is a positive
# or a negative number
def positive_or_negative():
   # traversing in a list
   for i in [5,6,7]:
   # checking whether the list element is greater than 0
      if i>=0:
         # printing positive number if it is greater than or equal to 0
         print ("Positive number")
      else:
         # Else printing Negative number and breaking the loop
         print ("Negative number")
         break
   # Else statement of the for loop
   else:
      # Statement inside the else block
      print ("Loop-else Executed")
# Calling the above-created function
positive_or_negative()
```


On executing, the above program will generate the following output


```python
Positive number
Positive number
Positive number
Loop-else Executed
```

## Nested Loops in Python
Python programming language allows the use of one loop inside another loop. The following section shows a few examples to illustrate the concept.
### Syntax
`<pre class="just-code notranslate language-python" data-lang`=`"python">`
for iterating_var in sequence:
   for iterating_var in sequence:
      statements(s)
      statements(s)
`</pre>`
The syntax for a nested **while** loop statement in Python programming language is as follows &minus;
`<pre class="just-code notranslate language-python" data-lang`=`"python">`
while expression:
   while expression:
      statement(s)
   statement(s)
`</pre>`
A final note on loop nesting is that you can put any type of loop inside any other type of loop. For example a for loop can be inside a while loop or vice versa.
### Example
The following program uses a nested-for loop to display multiplication tables from 1-10.
`<pre class="demo-code notranslate language-python" data-lang`=`"python3">`
for i in range(1,11):
   for j in range(1,11):
      k`=`i*j
      print ("&#123;:3d&#125;".format(k), end`=`' ')
   print()
`</pre>`
The print() function inner loop has end`=`' ' which appends a space instead of default newline. Hence, the numbers will appear in one row.
The last print() will be executed at the end of inner **for** loop.
