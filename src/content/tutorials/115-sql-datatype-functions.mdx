# SQL - Datatype Functions




The Data Type functions in SQL are a scalar functions that returns information about various data type values. Following are the SQL date type functions −


Sr.No.Function & Description1DATELENGTH()Returns the number of bytes used to represent any expression and also counts the leading and trailing spaces of the expression.2IDENT_CURRENT()Returns the last identity value generated for a specified table or view on an identity column.3IDENT_INCR()Returns the increment value of the identity column.4IDENT_SEED()Returns the original seed value.5SQL_VARIANT_PROPERTY()Returns the base data types and other information about a sql_variant value.
