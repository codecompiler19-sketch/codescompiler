# Python Tutorial

Learn Python by writing and running small programs instead of memorizing syntax. This tutorial starts with the building blocks you need as a beginner and then connects them to the larger Python topics covered throughout CodesCompiler.

The goal is simple: **understand what the code is doing, run it, change it, and learn from the result.**

## Start with a Small Python Program

Here is a complete Python program you can understand in a few seconds:

```python
name = "Python learner"
language = "Python"

print("Hello,", name)
print("You are learning", language)
```

### Output

```text
Hello, Python learner
You are learning Python
```

There are two useful ideas in this tiny example:

- A **variable** stores a value.
- `print()` sends a value to the program's output.

Try changing the value of `name` and run the program again. Learning Python becomes much easier when you experiment with working code.

## Why Learn Python?

Python is useful because the same language can be used for many different kinds of software. You can use it for:

- automation and scripting
- web applications
- data analysis
- testing and developer tools
- APIs and backend services
- desktop utilities
- scientific computing
- machine learning and AI

You do not need to learn all of these areas at once. Start with the language itself, then choose a direction after you are comfortable with the fundamentals.

## A Better Way to Practice Python

Reading an example is only the first step. Use this four-step loop for each new concept:

1. **Read** the explanation.
2. **Run** the example without changing it.
3. **Change** one part of the program.
4. **Solve** a small problem without looking at the answer.

For example, change the first program so that it asks for the user's name:

```python
name = input("What is your name? ")
print("Welcome,", name)
```

Now try to extend it:

- ask for a favorite programming language
- print both answers
- calculate a simple value entered by the user
- handle an invalid input

These small changes teach more than repeatedly copying the same example.

## Python Variables: Your First Building Block

A variable gives a value a name:

```python
age = 20
course = "Python"

print(age)
print(course)
```

Python determines the type of a value at runtime. You can inspect a value with `type()`:

```python
value = 42

print(type(value))
```

You will learn more about variables and types in the dedicated [Python Variables](/tutorial/python-variables/) and [Python Data Types](/tutorial/python-data-types/) tutorials.

## Python Conditions

A condition lets your program choose between different paths:

```python
score = 72

if score >= 50:
    print("Pass")
else:
    print("Try again")
```

Notice the indentation. In Python, indentation is part of the syntax, so the statements belonging to the `if` block must be indented consistently.

Continue with [Python if Statement](/tutorial/python-if-statement/) and [Python if-else](/tutorial/python-if-else/).

## Python Loops

Loops are useful when the same operation needs to happen several times:

```python
for number in range(1, 6):
    print(number)
```

Output:

```text
1
2
3
4
5
```

Once this makes sense, continue with [Python for Loops](/tutorial/python-for-loops/) and [Python while Loops](/tutorial/python-while-loops/).

## Python Lists

A list lets you keep several values together:

```python
languages = ["Python", "JavaScript", "SQL"]

for language in languages:
    print(language)
```

Lists are one of the most commonly used Python data structures. After learning the basics, explore [Python Lists](/tutorial/python-lists/), list access, modification, sorting, and list comprehensions.

## Handling Errors

Real programs encounter invalid input, missing files, network failures, and many other problems. Python provides exceptions so your program can respond to expected failures.

A simple example:

```python
try:
    number = int(input("Enter a number: "))
    print("Double:", number * 2)
except ValueError:
    print("Please enter a valid integer.")
```

Learn more in the [Python Exceptions](/tutorial/python-exceptions/) tutorial.

## Working with Files

Python can read and write files, which is useful for scripts, reports, data processing, and automation.

```python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Python makes file handling straightforward.")
```

The `with` statement automatically handles closing the file after the block finishes.

Continue with [Python File Handling](/tutorial/python-file-handling/) and [Python Read Files](/tutorial/python-read-files/).
