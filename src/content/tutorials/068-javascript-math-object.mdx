# JavaScript - Math




The JavaScriptmathobject provides properties and methods for mathematical constants and functions. Unlike other global objects, Math is not a constructor. All the properties and methods of Math are static and can be called by using Math as an object without creating it.


Thus, you refer to the constantpiasMath.PIand you call the sine function asMath.sin(x), where x is the method's argument.


# Syntax


The syntax to call the properties and methods of Math are as follows −


```javascript
var pi_val = Math.PI; // Property

var sine_val = Math.sin(30); // Method
```
