# CSS - Child Selectors




# Child Selectors in CSS


CSS child selector selects all the direct children of a particular element. This is denoted by '>' (Greater than) symbol. It will not select elements that are further nested inside the child elements.


## Syntax


The syntax for CSS child selectors is as follows:


```css
selector > child-selector {

    /* property: value; */

    color: #04af2f

}
```


## Child Selectors Example


In this example, we are changing the textcolorof the direct child element ofdivelement. The para element inside thespan tagremains unchanged as it is not a direct child of the div element.


```html
<!DOCTYPE html>

<html lang="en">

<head>

    <title>Document</title>

    <style>

        .myDiv > p {

            color: #04af2f;

        }



    </style>

</head>

<body>

    <div class="myDiv">

        It is a paragraph element. Direct child of div element.

        <span>This is a p element inside div but not direct child of div.</span>        

    </div>

    This is a p element outside div.    

</body>

</html>
```

</body>

</html>
